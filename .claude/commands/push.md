---
name: git:publish
description: Review, stage, commit with clean identity, and push to main.
allowed-tools:
  - Bash
---

<objective>
Stage all relevant changes, commit them using the local user's identity (no AI attribution), and push to the main branch.
</objective>

<process>
1. **Review:** Run `git status` and `git diff` to review all staged and unstaged changes.
2. **Stage:** Stage all modified and untracked files (strictly excluding secrets, `.env`, or binaries).
3. **Identity Check:** Explicitly run `git config user.name` and `git config user.email` to ensure the local user identity is active.
4. **Commit:** - Write a 1-line summary (< 72 chars).
   - Execute the commit using: `git commit -m "[message]"`
5. **Push:** Push to the main branch: `git push origin main`.
6. **Report:** Provide the short commit hash and the final message.
</process>

<guardrails>
- **NO ATTRIBUTION:** Do not include "Co-authored-by: Claude", "Generated by Claude", or any AI-related signatures in the message.
- **CLEAN MESSAGE:** If the `.claude/settings.json` fails to strip attribution, you must manually edit the message to ensure it is 100% human-like.
- **BRANCH SAFETY:** If the push fails due to being behind origin, stop and ask for a rebase/pull.
</guardrails>
